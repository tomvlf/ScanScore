# Bijdragen

1. Open eerst een issue voor ingrijpende wijzigingen.
2. Maak een korte featurebranch.
3. Voeg tests toe voor security- of databaselogica.
4. Voer `npm ci`, `npm run check` en `npm test` uit.
5. Commit nooit secrets, dumps, QR-waarden of persoonsgegevens.

Door bij te dragen stem je ermee in dat je bijdrage onder de MIT-licentie wordt gepubliceerd.
